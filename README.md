# 10년 일기 (PWA)

같은 날짜(월/일)의 10년을 한 페이지에 모아 쓰는 일기장입니다. 해마다 같은 날 같은 질문을 받고, 작년·재작년의 내가 쓴 글을 바로 아래에서 볼 수 있습니다.

## 기능
- **오늘의 페이지**: 선택한 월/일의 10년치 칸(시작 연도부터 10년), 오늘 칸 강조, 미래 날짜는 잠금, 2월 29일은 윤년에만 작성
- **오늘의 질문**: 날짜마다 고정된 질문
- **기분 이모지**와 자동 저장
- **달력**: 기록한 날 표시, 같은 날짜에 기록된 해의 수(점), 전체/올해/연속 기록 통계
- **검색**: 전체 일기 본문 검색
- **설정**: 시작 연도, JSON 백업 내보내기/가져오기, 밝게/어둡게 테마, 전체 삭제
- **PWA**: 홈 화면에 설치, 오프라인 동작(서비스 워커)

데이터는 브라우저의 `localStorage`에만 저장되며 서버로 전송되지 않습니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 백업을 내보내 주세요.

## 실행
서비스 워커는 `http://localhost` 또는 HTTPS에서만 동작합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

GitHub Pages 등 정적 호스팅에 그대로 올리면 휴대폰에서 "홈 화면에 추가"로 설치할 수 있습니다.

## 파일
- `index.html`, `style.css`, `app.js`, `questions.js` — 앱
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA 설정 (파일 수정 시 `sw.js`의 `VERSION`을 올리세요)
